매칭과 흐름 — 짝짓기와 실어 나르기

핵심 질문 — 서로 겹치지 않게 짝을 가장 많이 지으려면, 그리고 관을 따라 물건을 가장 많이 보내려면 어떻게 할까?

매칭은 선을 골라 짝을 짓되 한 점이 두 짝에 들어가지 않게 하는 것이에요. 네트워크 흐름은 선마다 크기(용량)가 정해진 관을 따라 출발점 s에서 도착점 t로 물건을 보내는 문제예요. 둘 다 「더 늘릴 길」을 찾아 한 번씩 늘려 가는 방법으로 풀어요.

4쌍원자료 멘토·멘티 그래프의 최대 매칭
5원자료 네트워크의 최대 흐름 |f|
5가장 좁은 자르는 선의 용량 = 최대 흐름
2번빈 관에서 시작해 최대 흐름까지 늘리는 데 필요했던 횟수

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

오늘은 몸으로 하는 수업이에요. 1조는 멘티, 2조는 멘토가 되어 짝을 지어 보세요.

시간이 맞는 사람끼리만 짝이 될 수 있대요!

미공개 X2

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 선을 골라 겹치지 않는 짝을 가장 많이 짓고(최대 매칭), 관 크기 안에서 s에서 t로 최대한 많이 보냅니다(최대 흐름).
  2. 왜 중요한가: 「제한된 자원을 가장 잘 나누기」의 두 기본 모형이에요. 그리고 최대 흐름은 「가장 좁은 자르는 선」과 늘 같다는 아름다운 정리가 있어요.
  3. 생활·현장에서는: 멘토 배정, 수강 신청 배정, 장기 기증 짝 맞추기(매칭), 물류·교통·통신망 용량 계산(흐름)에 쓰여요.

코드·수식을 몰라도 됩니다. 그림을 눌러 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • M — 매칭 (Matching) — 고른 짝 모음
  • f(e), c(e) — 선 e에 흐르는 양(flow), 선 e의 용량(capacity)
  • |f| — 흐름의 값 — t에 도착하는 양
  • δ(S) — 델타 에스 — S에서 바깥으로 나가는 선 모음 (자르는 선)

1단계 · 매칭 — 한 사람은 한 짝만, 짝은 가장 많이

방법: 짝을 바꿔 늘리는 길 찾기일상: 멘토·멘티 배정
박사

상황 질문 — 멘티 4명과 멘토 4명이 있어요. 시간이 맞는 사람끼리만 짝이 될 수 있다면, 몇 쌍까지 지을 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 겹치지 않게 짝을 가장 많이 짓고 싶어요.
  2. 앞 방법의 한계: 먼저 보이는 짝부터 지으면(욕심쟁이 방법) 나중에 짝 없는 사람이 남을 수 있어요.
  3. 해법: 짝 없는 사람에서 출발해 「안 쓴 선, 쓴 선」을 번갈아 따라 짝 없는 상대까지 가는 길(늘리는 길)을 찾고, 그 길의 짝을 뒤집어 한 쌍씩 늘려요. 늘리는 길이 없으면 최대예요.
쉽게 말하면 — 이미 지은 짝을 바꿔서라도 한 쌍 더.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

M = {(u₁, v₁), (u₂, v₃), …}에서 중괄호 안의 괄호 쌍은 뭐예요?

학교 수학으로 보면: 중학교 「순서쌍」 (x, y)와 같아요. 여기서는 (멘티, 멘토) 짝 하나를 뜻하고, 중괄호는 짝들의 모음이에요.

식 조각읽는 법뜻
(u, v)순서쌍멘티 u와 멘토 v의 짝 = 고른 선 하나
M엠고른 짝들의 모음 (매칭)
|M|엠의 크기짝의 수
숫자로 한 번 해 보기

원자료 M = {(u₁, v₁), (u₂, v₃), (u₃, v₂), (u₄, v₄)} → |M| = 4, 모두 짝 있음(완전 매칭)

겹침 확인: u는 1, 2, 3, 4가 한 번씩, v는 1, 3, 2, 4가 한 번씩 → 겹침 없음 ✓

「셋이 둘만 원함」: u₁, u₂, u₃가 원하는 멘토가 v₁, v₂ 둘뿐 → 최대 3쌍

조수 하루 (수강생)

셋이 둘을 나눠 가질 수는 없으니, 숫자만 세도 「최대 몇 쌍」의 한계가 보이네요!

일상으로 치면

역할극에서처럼, 먼저 짝을 지은 사람이 상대를 양보하고 다른 사람과 다시 짝을 지으면 전체 짝이 늘 수 있어요. 더 이상 이런 양보 사슬이 없으면 최대예요.

그래프 이론에서는

매칭은 끝점을 공유하지 않는 선들의 모음이에요. 짝이 가장 많은 것이 최대 매칭, 모든 점이 짝을 가지면 완전 매칭이에요. 원자료 그래프는 완전 매칭(4쌍)이 있어요. 왼쪽 사람 몇 명이 원하는 상대가 그 인원보다 적으면 완전 매칭은 없어요(홀의 결혼 정리).

박사

먼저 직접 짝을 골라 보고, 그다음 「컴퓨터: 최대 매칭 찾기」와 비교해 보세요.

주판봇

선이 많은 u부터 짝을 지으면 금방 4쌍이에요!

초파리 연구원

u1–v2부터 고르면 어떻게 되는지 해 봐. 그다음에 바꾸는 법도.

짝짓기 실험 — 선을 눌러 짝 고르기

풀이 — 한 걸음씩

  1. 선을 누르면 짝(빨강)이 되고, 한 사람이 두 짝에 들어가면 주황 점선으로 경고해요.
  2. u1–v2, u3–v4를 먼저 고르면 u4가 짝을 못 찾아요. u1을 v1로, u3을 v2로 바꾸면 u4–v4가 생겨요.
  3. 원자료 정답 M은 4쌍, 모두가 짝이 있는 완전 매칭이에요.
  4. 「셋이 둘만 원함」에서는 아무리 바꿔도 3쌍이 최대예요. 인원 대비 상대가 모자라는 무리가 있기 때문이에요.
이 단계의 한계 — 여기서는 「시간이 맞나」만 봤어요. 실제 배정에는 선호 순위가 있어서, 짝 수뿐 아니라 「누구도 더 나은 짝으로 함께 옮기고 싶지 않은」 안정 매칭을 따지기도 해요.
박사의 해석 — 매칭 결과가 「모두 배정 완료」가 아니라면, 홀의 조건으로 어느 무리의 상대가 모자라는지 찾아 그 쪽 인원(멘토)을 늘리는 것이 해법이에요.

2단계 · 네트워크 흐름 — 관 크기 안에서 최대한 보내기

방법: 더 흘릴 길을 찾아 한 번씩 늘리기일상: 택배 트럭 배차
박사

상황 질문 — 물류 센터 s에서 지점 t로 하루 동안 트럭을 보내요. 도로마다 보낼 수 있는 트럭 수가 정해져 있다면, 최대 몇 대가 t에 도착할까요?

왜 이 방법을 쓰나

  1. 문제 상황: 관(도로) 크기를 지키면서 s에서 t로 가장 많이 보내고 싶어요.
  2. 앞 방법의 한계: 출발 도로 용량을 더하는 계산(4 + 3 = 7)은 중간의 좁은 도로를 무시해요.
  3. 해법: 아직 여유가 있는 길(증가 경로)을 찾아, 그 길의 가장 좁은 여유만큼 더 보내기를 반복해요(포드–풀커슨 방법). 더 흘릴 길이 없으면 최대이고, 그때 막힌 곳들이 가장 좁은 「자르는 선」이에요.
쉽게 말하면 — 고속도로 전체 처리량은 가장 막히는 구간이 정한다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

0 ≤ f(e) ≤ c(e)는 「흐름 보존」이라고 적혀 있던데, 보존이 무슨 뜻이에요?

학교 수학으로 보면: 중학교 「부등식」이에요. 0 ≤ f ≤ c는 「흐르는 양은 0 이상, 관 크기 이하」라는 뜻이에요. 보존은 다른 규칙이에요.

식 조각읽는 법뜻
0 ≤ f(e) ≤ c(e)용량 제한관마다 흐르는 양은 0부터 관 크기까지
들어온 양 = 나간 양흐름 보존s, t가 아닌 점에서는 쌓이거나 새지 않음
|f|흐름의 값t에 도착하는 양
min Σ c(e), e ∈ δ(S)최소 절단s 쪽 S에서 나가는 관 용량 합의 최솟값
숫자로 한 번 해 보기

원자료 흐름: s→a 3/4, s→b 2/3, a→c 3/4, a→b 0/2, b→d 2/3, c→t 3/3, d→t 2/2

보존 확인: a는 들어옴 3 = 나감 3 + 0, b는 2 + 0 = 2, c는 3 = 3, d는 2 = 2 ✓

|f| = 3 + 2 = 5 · 자르는 선 S = {s, a, b, c, d}: c→t 3 + d→t 2 = 5 → 최대 흐름 = 최소 절단 = 5

조수 하루 (수강생)

용량 제한(관 크기)과 흐름 보존(들어온 만큼 나감)은 다른 규칙이었네요. 원자료 제목이랑 식이 짝이 안 맞았던 거예요.

데이터·코드 첫걸음 — 흐름 데이터는 선 목록에 「용량」 열을 하나 더 붙인 표

1장의 선 목록(from, to)에 「capacity(용량)」 열을 붙이면 흐름 문제의 입력이 끝나요. 계산이 끝나면 「flow(흐르는 양)」 열이 하나 더 생겨요.

흐름 보존은 표로 확인할 수 있어요. 점마다 to 열에 그 점이 있는 줄의 flow 합(들어옴)과 from 열에 있는 줄의 flow 합(나감)을 비교해요.

from, to, capacity, flow
s, a, 4, 3
s, b, 3, 2
a, c, 4, 3
a, b, 2, 0
b, d, 3, 2
c, t, 3, 3
d, t, 2, 2

점 a: 들어옴(to = a) 3, 나감(from = a) 3 + 0 = 3 ✓

flow = capacity인 줄(c→t, d→t)이 꽉 찬 관 → 병목 후보

엑셀의 「조건부 합계(SUMIF)」를 써 본 적이 있다면, 흐름 보존 확인이 바로 그 계산이에요.

일상으로 치면

택배 트럭이 아무리 많아도 지점 t로 들어가는 마지막 두 도로가 3대, 2대뿐이면 하루 5대가 끝이에요. 출발 도로를 넓혀 봐야 소용없고, 가장 좁은 곳을 넓혀야 해요.

그래프 이론에서는

네트워크 흐름은 관마다 용량 제한(0 ≤ f(e) ≤ c(e))과 중간 점의 흐름 보존(들어온 양 = 나간 양)을 지키며 s에서 t로 보내는 양 |f|를 최대로 하는 문제예요. 최대 흐름은 s와 t를 가르는 자르는 선 중 용량 합이 가장 작은 값과 같아요(최대 흐름 최소 절단 정리). 원자료 예시는 5예요.

박사

단추 ①과 ②를 번갈아 눌러 보세요. 몇 번 만에 더 흘릴 길이 없어지나요?

주판봇

①로 찾은 길이 끝나면 아직 남은 관이 많아 보이는데, 진짜 끝이에요?

초파리 연구원

보라색 선을 봐. s 쪽에서 t 쪽으로 넘어가는 관이 전부 꽉 찼어. 거기가 병목이야.

최대 흐름 실험 — 더 흘릴 길 찾기와 흘려보내기

풀이 — 한 걸음씩

  1. 처음에는 모든 관이 0. ①을 누르면 s → a → c → t가 빨갛게 나오고 가장 좁은 여유는 3이에요.
  2. ②로 3을 보내고 다시 ①: s → b → d → t, 여유 2. ②로 보내면 |f| = 5.
  3. 다시 ①을 누르면 더 흘릴 길이 없어요. s에서 갈 수 있는 점(초록)과 없는 점(보라) 사이의 관 c→t, d→t가 꽉 찬 병목이에요.
  4. 병목 용량 합 3 + 2 = 5 = 최대 흐름. 출발 쪽 용량 합 7은 답이 아니에요.
이 단계의 한계 — 이 실험은 물건 한 종류, 하루 한 번만 봤어요. 실제 물류는 여러 물건, 시간대, 비용이 함께 얽혀 「최소 비용 흐름」 같은 더 큰 문제가 돼요.
박사의 해석 — 최대 흐름의 진짜 쓸모는 「어디를 넓혀야 하나」를 알려 주는 것이에요. 최소 절단에 속하지 않은 관을 넓히면 처리량은 하나도 안 늘어요(실전 연습장에서 확인).
원자료 인포그래픽 보기 (영어 그림)

원자료 오른쪽 흐름 그림(s, a, b, c, d, t), |f| = 5 = cut capacity, Max-flow min-cut theorem.

원자료의 「Flow conservation」 제목 아래 식 0 ≤ f(e) ≤ c(e)는 흐름 보존이 아니라 용량 제한이에요. 이 페이지에서는 「용량 제한: 0 ≤ f(e) ≤ c(e)」와 「흐름 보존: 중간 점에서 들어온 양 = 나간 양」 두 규칙으로 나눠 씁니다.
