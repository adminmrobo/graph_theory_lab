# 그래프 이론 연구실 — 점과 선으로 관계를 보는 법

데이터와 코드를 처음 공부하는 분을 위한 **그래프 이론** 연구실 해설 시리즈예요. 인포그래픽 9장의 아홉 주제를 **9개 장**(장마다 2단계, 20~25분)과 **실전 연습장**으로 풀었고, 장마다 상담 · 데이터 시각화 조별발표 · 개인발표 · 토론 · 역할극 장면으로 개념이 어디에 쓰이는지 먼저 보여 줘요. 본문에는 코드가 없고, 궁금한 분만 「파이썬 코드로 보면」 접기 상자를 펼치면 돼요.

- 심판: 박사 · 1조 「꼭짓점조」: 조장 주판봇, 인턴 시아(인턴1), 조수 하루, 미공개 X1 · 2조 「연결선조」: 조장 초파리 연구원, 인턴 모아(인턴2), 미공개 X2, X3
- 장마다 두 조장이 「조장 대결」로 맞붙고, 심판 박사는 계산 결과로만 판정해요.

**바로 보기:** https://adminmrobo.github.io/graph_theory_lab/ (GitHub Pages를 켜면 열려요)

## 목차

| 기둥 | 장 |
|---|---|
| 1 · 점과 선의 기초 | 01 그래프 기초(첫 상담 + 차수 막대그래프 발표) · 02 그래프 표현(행렬 열지도 vs 저장 공간 시각화 대결) · 03 경로와 연결(시아 개인발표 + 상담) |
| 2 · 길과 나무 | 04 트리(모아 상담 + X3 개인발표) · 05 오일러와 해밀턴(조별 토론) |
| 3 · 그리고 나누기 | 06 평면성과 색칠(노선도 vs 시간표 시각화 대결) · 07 매칭과 흐름(역할극 + 상담) |
| 4 · 가장 좋은 답과 숫자로 보기 | 08 최단 경로(하루 개인발표) · 09 스펙트럼 그래프 이론(상담 + 졸업 조별발표, 심화) |
| 마지막 장 | 실전 연습장 — 배달 길찾기 센터 · 시험 시간표 사무실 · 물류 관 증설 본부 |

## 구성

- `index.html`, `NN_*.html`, `practice/index.html` — 페이지 (외부 라이브러리 없음, 글꼴만 외부 요청, 브라우저 저장소 사용 안 함)
- `content/` — 장별 내용 데이터, `tools/build.py` — 조립 (`python3 tools/build.py`)
- `assets/` — 공용 스타일·캐릭터·퀴즈·대결(`lab.css`, `lab.js`, `sprites.js`), 그림 실험 20개(`src/g1~g3.js` → `widgets.js`), 실전 연습장(`practice.js`), 지식 색인·꾸러미(`js/kgx.js`)
- `img/source/` — 원자료 인포그래픽 9장, `img/og/` — 공유 미리보기(임시), `img/cover/` — 표지(제작 예정)
- `docs/IMG_specs.md` — 표지 11장 지시문(16비트 RPG 픽셀아트, 흰 배경)
- `docs/WORK_NOTES.md` — 독자 진단, 원자료 바로잡기, 검산, 교수법 자가 채점(21/21)
- `docs/PERSONA_REVIEW.md` — 페르소나 검사(데이터·코드를 처음 배우는 학생 중심)와 반영 내역
- 검사 도구: `tools/check.py`(390·1280px 화면), `tools/test_duels.py`(조장 대결), `tools/test_practice.py`(계산 검산 + 실전 연습장 미션), `tools/make_og.py`

## 원자료와 다른 곳

원자료 표지의 스펙트럼 {−2, −1, 0, 0, 1, 3}은 {−2, −1.17, 0, 0.69, 2.48}로, 7장의 「흐름 보존」 식은 「용량 제한」으로 바꿔 썼어요. 자세한 내용은 각 단계의 「원자료 인포그래픽 보기」 상자와 `docs/WORK_NOTES.md`에 있어요.
