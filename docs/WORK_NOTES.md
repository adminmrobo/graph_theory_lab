# 작업 메모 — 그래프 이론 연구실

## 1. 독자 진단과 방향

- 대상 독자: 「데이터와 코드를 처음 공부하는 학생」. 9-1장 기준 **혼합형**(수식 막힘 + 해석 막힘)으로 가정했어요. 수식 앞에 그림·작은 숫자, 기호는 하나씩 읽는 법부터, 코드는 본문에서 빼고 접기 상자에만.
- 데이터·코드 입문자를 위해 「데이터·코드 첫걸음」 상자를 6곳(01·02·03·04·08·09장)에 넣었어요: 선 목록(CSV) 표, 딕셔너리·행렬·짝 목록, 길 = 이름 리스트, 부모 표, 대기 줄(힙), 고윳값 한 줄 계산과 확인법.
- 모든 단계에 「파이썬 코드로 보면 (몰라도 됩니다)」 접기 상자(networkx 코드 한 줄 + 뜻 한 줄)를 두었어요.
- 구성: 원자료 시리즈 9주제 = 9장(장마다 2단계) + 마지막 장 실전 연습장. 09장 2단계(라플라시안)는 심화로 접어 둠.
- 캐릭터: 심판 박사 · 1조 「꼭짓점조」(조장 주판봇, 시아=인턴1, 하루, X1) · 2조 「연결선조」(조장 초파리, 모아=인턴2, X2, X3).
- 장면(시나리오) 16개: 상담 5(01·03·04·07·09), 조별발표 6(01 · 02 두 조 · 06 두 조 · 09 졸업), 개인발표 3(03 시아 · 04 X3 · 08 하루), 토론 1(05), 역할극 1(07). 데이터 시각화 조별발표에는 실제로 눌러 보는 차트(차수 막대그래프, 행렬 열지도, 평면 그림, 색칠 시간표)를 슬라이드 안에 넣었어요.
- 원자료: 2026-11-26에 받은 인포그래픽 9장(@eeanimation) → `img/source/src00~08.webp` (00 = 시리즈 표지, 01~08 = 각 주제; 9번 주제 스펙트럼은 표지의 그림을 씀).

## 2. 원자료 바로잡기 (「원자료의 A를 이 페이지에서는 B로 바꿉니다」)

- 09장 1단계 (원자료 표지): 원자료의 Spec(A) = {−2, −1, 0, 0, 1, 3}을 이 페이지에서는 {−2, −1.17, 0, 0.69, 2.48}로 바꿉니다. 점 5개 그래프의 고윳값은 5개여야 하는데 6개이고, 합도 0이어야 하는데 1이에요. 표지 그래프(선 a–b, a–c, b–d, b–e, c–e, d–e)의 특성다항식 λ(λ + 2)(λ³ − 2λ² − 2λ + 2)의 근으로 다시 계산했어요(제곱 합 12 = 2 × 선 6개 확인).
- 07장 2단계 (원자료 7장): 원자료 「Flow conservation」 제목 아래 식 0 ≤ f(e) ≤ c(e)는 흐름 보존이 아니라 용량 제한이에요. 이 페이지에서는 「용량 제한: 0 ≤ f(e) ≤ c(e)」와 「흐름 보존: 중간 점에서 들어온 양 = 나간 양」으로 나눠 씁니다.
- 03장 1단계 (원자료 3장): 원자료 위 그림은 화살표 선과 방향 없는 선, c ⇄ d 두 방향 선이 섞여 있어요. 실험은 방향 없는 그래프로 단순하게 바꿔 보여 줍니다(이 단계의 한계에 밝힘).
- 04장 2단계 (원자료 4장): 원자료 신장 트리 그림에는 무게가 없어요. 같은 모양에 설명용 공사비를 붙여 최소 신장 트리(15억)까지 다뤘고, 원자료 그림의 트리(같은 공사비로 18억)도 올바른 신장 트리라고 밝혔어요.
- 01장 2단계 (원자료 1장): 무게 그래프의 deg(B) = 3은 선 개수예요. 무게 합 6은 「가중 차수」로 이름을 나눠 설명했어요(원자료가 틀린 것은 아님).
- 그 밖의 원자료 값(차수, 인접 리스트·행렬, 경로 s → a → b → t, 트리 |E| = n − 1, K₅ 해밀턴 사이클, V − E + F = 5 − 8 + 5 = 2, χ = 4, 매칭 M, |f| = 5 = 절단 용량, 다익스트라 대기 줄 여섯 상자, d(t) = 8)는 모두 검산해 맞았어요.

## 3. 검산 기록

- `tools/test_practice.py`: 해밀턴 사이클 수(K₅ 12, 정육면체 6, 페테르센 0), 채색수(원자료 삼각형 4, C₅ 3, C₆ 2, 시험 시간표 3), 최소 신장 트리 15, 최대 흐름 5, 최단 거리 8, 고윳값 {−2, −1.17, 0, 0.69, 2.48}, 홀수 차수 점 수(쾨니히스베르크 4, 집 모양 2, 네모 0)를 페이지 안 계산과 비교 — 모두 통과. 실전 연습장 미션 9개는 「조작 전 통과 없음 → 정답 조작 뒤 통과」 확인.
- networkx로 따로 검산: 배달 지도 최단 12분(평소, 센터–B–D–F–고객) / 14분(퇴근, 센터–A–C–F–고객), 구간 최소 길은 퇴근 시간에 16~20분; 물류 증설 효과 평소 c→t·d→t +1, 공사 중 a→c +2; 2학기 시간표 자동 칠하기 3색 > 최소 2색; 반 친구 라플라시안 λ₂ = 0.172.
- 조장 대결 9개는 `tools/test_duels.py`로 판정 확인(02·04·07장 주판봇 조장 승, 나머지 초파리 조장 승 → 최종 2조 6승 1조 3승).
- 화면 점검: `tools/check.py`로 11쪽 × 390·1280px 가로 넘침 0, 콘솔 오류 0, 빈 캐릭터 그림 0, 위젯 실패 0.
- 금지어 전체 검색 0건(독자를 포기한 사람으로 부르는 말, 오르내리는 기구에 빗댄 말, 뚫고 지나간다는 말, 구획 단위어).
