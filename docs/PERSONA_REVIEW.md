# 페르소나 검사 — 그래프 이론 연구실 (데이터·코드를 처음 배우는 학생 중심)

검사일 2026-11-26 · 대상: 오리엔테이션 + 9개 장 + 실전 연습장 (11쪽) · 자기 결과물이라 문제 찾기에 무게를 둠

## 0. 대상 요약

인포그래픽 9장의 아홉 주제를 9개 장(장마다 2단계)과 실전 연습장으로 푼 연구실 해설이에요. 심판 박사와 두 조(조장 주판봇·초파리)가 상담·조별발표·개인발표·토론·역할극 장면으로 개념을 먼저 보여 주고, 단계마다 그림 실험·수식 상자·퀴즈가 붙어요. 본문에는 코드가 없고 접기 상자에만 networkx 코드가 있어요.

측정 근거(접기 상자·색인 제외 본문): 장당 7,770~9,459자, 본문 코드 0개, 장당 퀴즈 5문항, 영어 단어 7~36개(가장 많은 곳: 08장 relax·heap·BFS, 01장 vertex·edge·degree). 낯선 고유명·전문용어: 05장 NP-완전·디랙·플뢰리·히어홀처, 06장 쿠라토프스키, 09장 이분 그래프·고유벡터.

## 5. 정리

입문 쪽(A·B)은 「장면 먼저, 코드는 접기」 구성에 높은 점수를 줬지만, 코드를 실제로 돌려 보려는 B는 실행 안내가 없어서 가장 낮게 평가했어요. 전문가 쪽(E·F)은 원자료 바로잡기와 한계 문장을 높게 봤고, F는 09장의 「드물다」 한 문장을 정확성 오류로 지적했어요. 비용 대비 효과가 가장 큰 1~6순위(정확성 정정, 코드 실행 안내, 첫걸음 상자 3곳, 용어 풀이, 용어 정리표, 배지)는 모두 이번에 반영했어요. 남은 과제는 표지 그림(외부 생성 도구 필요), 입력형 계산 문제, 강의자용 가이드예요.
