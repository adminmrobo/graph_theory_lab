# 강의자용 진행 가이드 — 그래프 이론 연구실

데이터·코드를 처음 배우는 학생들과 이 시리즈로 수업할 때 쓰는 진행표예요. 한 장 = 한 차시(75분 기준)이고, 50분 수업이면 「줄일 때」 표시를 빼고 진행해요. 모든 숫자는 페이지와 같은 설명용 예시값이에요.

## 1. 수업 전 준비

**조 편성 — 페이지의 두 조를 그대로 따라 해요.** 학생 6~8명을 한 조로 묶고, 조 안에서 아래 역할을 돌아가며 맡아요(장마다 바꾸기).

| 역할 | 페이지 속 인물 | 하는 일 |
|---|---|---|
| 조장 | 주판봇 · 초파리 | 조장 대결에서 조의 답을 정하고 근거를 말함 |
| 발표 | 모아 · 시아 | 장면의 조별발표·개인발표를 대신 읽고 설명 |
| 그림 | X2 | 그림 실험을 화면에 띄워 조작 |
| 집계 | X3 | 「숫자로 한 번 해 보기」를 손으로 계산해 확인 |
| 질문 | 하루 · X1 | 수식 상자의 질문, 막힌 곳을 대표로 질문 |

**준비물:** 프로젝터 1대, 조마다 노트북·태블릿 1대 이상(페이지는 인터넷만 되면 설치 없이 열림), 포스트잇, (선택) 끈·색 스티커 — 07장 역할극·06장 색칠에 씀.

**처음 한 번만:** 오리엔테이션 페이지의 「그래프 용어 한 장 정리」를 인쇄해 나눠 주면 학생들이 막힐 때 스스로 찾아봐요.

## 2. 한 차시 기본 흐름 (75분)

| 시간 | 할 일 | 페이지 위치 |
|---|---|---|
| 0~5분 | 3줄 요약 읽기, 오늘의 핵심 질문을 칠판에 적기 | 처음 오신 분께 |
| 5~20분 | **오늘의 장면** — 학생이 역할을 나눠 대사 읽기, 심판 한 줄 평은 강의자가 읽기 | 오늘의 장면 |
| 20~40분 | **1단계** — 상황 질문 → 왜 이 방법 → 수식 상자(집계 담당이 손계산) → 그림 실험 → 퀴즈 | 1단계 |
| 40~60분 | **2단계** — 같은 순서 (줄일 때: 실험만 하고 수식 상자는 과제로) | 2단계 |
| 60~68분 | **AI 판단 코너** — 조별로 AI 답의 오류를 찾아 포스트잇에 한 줄로 | AI 판단 |
| 68~73분 | **조장 대결** — 조마다 누가 맞을지 먼저 손들어 투표 → 대결 단추로 판정 | 대결 |
| 73~75분 | 정리표 한 줄 읽기, 과제 안내 | 정리 |

강의자는 「심판 박사」 역할만 맡아요. 판정은 늘 계산(대결 단추, 실험 결과)으로 하고, 강의자 의견으로 승패를 정하지 않아요. 학생이 막히면 페이지의 박사 대사처럼 「여기서 멈춰도 괜찮아요」라고 말해 주세요.

## 3. 장별 진행 메모

| 장 | 오늘의 장면 운영 | 실험에서 꼭 시킬 것 | 학생이 자주 틀리는 곳 | 과제 |
|---|---|---|---|---|
| 01 그래프 기초 | 상담(하루 · 박사) 2명 + 2조 발표 4명. 막대그래프를 학생이 직접 눌러 보게 | 선을 마구 더해도 「차수 합 = 2 × 선 수」가 안 깨지는 것 확인 | 차수 합을 선 수로 답함 | 연습 01-1·2 |
| 02 표현 | 두 조가 각각 발표, 상대 조가 질문 1개씩. 「무리끼리 모아서」를 누르기 전에 무엇이 보일지 예상시키기 | 방향 있음/없음을 바꿔 행렬 1이 한 곳만 바뀌는 것 확인 | 행렬 자리 수와 리스트 자리 수 혼동 | 연습 02-1·2 |
| 03 경로와 연결 | 시아 역 학생이 자기 통학길로 바꿔 발표해도 좋음 | 「다리 보기」로 사이클 위 선은 왜 빨갛지 않은지 설명시키기 | 길이를 점 수로 셈 | 연습 03-1·2 |
| 04 트리 | 모아 상담 → 학생에게 「상사가 둘인 사람」 예를 들게 하기 | 원자료 트리(18억)와 크루스칼(15억)을 꼭 비교 | 싼 선 6개를 무조건 고름(사이클) | 연습 04-1·2 |
| 05 오일러·해밀턴 | 조별 토론: 1조 오일러 편, 2조 해밀턴 편, 발언 2분씩 | 쾨니히스베르크에서 직접 실패해 보기 → 차수 세기 | 오일러 조건을 해밀턴에 적용 | 연습 05-1·2 |
| 06 평면성·색칠 | 두 조 발표. K₅를 끝까지 풀려고 하는 학생에게 「미리 보는 검사」를 읽게 | 다섯 명 원탁을 2색으로 칠하다 막히는 경험 | 「삼각형 없음 = 2색」 | 연습 06-1·2, 연습장 시간표 사무실 |
| 07 매칭·흐름 | 역할극은 실제 끈으로 하면 가장 좋음(10분). 상담은 2명 낭독 | ①②를 번갈아 눌러 병목(보라)을 찾기 | 출발 쪽 용량 합을 최대 흐름으로 답함 | 연습 07-1·2, 연습장 물류 본부 |
| 08 최단 경로 | 하루 역 학생이 대기 줄 표를 칠판에 한 줄씩 채우며 발표, 다른 조가 검증 | d → t 길이를 4로 바꿔 길이 바뀌는 순간 찾기 | 구간 수가 적은 길을 최단으로 봄 | 연습 08-1·2, 연습장 배달 센터 |
| 09 스펙트럼 (심화) | 상담 낭독 후 「이웃 숫자 모아 오기」를 삼각형으로 손으로 해 보기. 2단계는 희망자만 | 원자료 값(회색)과 계산 값(빨강)의 개수·합 비교 | 가장 큰 고윳값 = 최대 차수라고 단정 | 연습 09-1·2 |

## 4. 평가

- **연습 문제(18개):** 페이지가 바로 채점하지만 점수를 저장하지 않아요. 제출이 필요하면 학생에게 「전체 점수」 화면을 캡처해 내게 해요.
- **실전 연습장 미션(9개):** 미션 통과 표시 화면을 캡처해 내게 해요. 「함정 관찰」 미션에서 무엇을 봤는지 한 문장 설명을 함께 받으면 이해를 확인할 수 있어요.
- **조별발표:** 아래 세 항목으로 3점씩, 9점 만점.

| 항목 | 3점 기준 |
|---|---|
| 데이터 → 집계 → 그림의 순서 | 무엇을 셌는지, 그림의 축이 무엇인지 말함 |
| 해석 한 문장 | 「이 숫자는 ○○라는 뜻」을 붙임 (예: 색 수 = 시간대 수) |
| 한계 | 안 되는 경우·경계값을 숨기지 않음 (예: K₅, 예준) |

- **AI 판단 코너:** 포스트잇의 한 줄이 「어느 규칙으로 걸렀는가」(차수 합 짝수, 고윳값 합 0 등)를 말하면 통과.

## 5. 데이터·코드 연결 (선택, 실습실 수업)

각 단계의 「파이썬 코드로 보면」 상자를 Colab에서 그대로 실행하게 해요. 첫 줄에 `import networkx as nx`를 넣는 것만 알려 주면 돼요. 목표는 코드를 외우는 것이 아니라 **페이지의 숫자와 코드 결과가 같은지 비교하는 것**이에요. 다른 숫자가 나오면 그게 가장 좋은 토론거리예요.

## 6. 진도 제안

- **한 학기 짧은 단원(4주):** 01·02 → 03·04 → 05·06 → 08 + 실전 연습장
- **한 학기 전체(10주):** 장마다 1주 + 마지막 주 실전 연습장과 연습 문제
- **특강 1회(2시간):** 오리엔테이션 → 01장 장면·1단계 → 08장 1단계 → 실전 연습장 배달 센터
